# Adult RPG character refinement

Approved direction: all fifteen characters move away from toy proportions toward grounded, adult RPG character design. Keep their names, clothing colours, story props and community identities. Spirits remain fictional interpretations; adult styling does not add horror violence or change the folklore notes.

Asset contract: approximately seven-head human proportions, smaller expressive eyes, defined noses and lips, articulated elbows and knees, restrained idle breathing and weight shifts. Walking is in place with opposing arms and legs; props remain attached. Floating spirits hover, and Pocong retains a small bound-foot hop. Four seamless clips remain named Idle, Walk, Wave and Celebrate. DXF follows the updated static geometry.

Runtime contract: Three.js uses smooth clip blending, soft contact shadows and eased viewing rotation. Pause, offscreen suspension and reduced motion remain supported. The Unity delivery contains the same GLBs plus a Generic animation setup helper and runtime controller. It is an import package, not a Unity-tested project: the Editor is unavailable on this Mac and the user selected package preparation.

Limits: these are original procedural, articulated mesh characters, not photogrammetry, skinned humanoid rigs or scanned faces. No claim of AAA photorealism or humanoid retargeting. Unity requires its glTFast importer, installed separately via Package Manager.
